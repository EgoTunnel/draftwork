# Code of conduct

Draftwork follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and remember that the people affected by this tool include students who aren't in the room. Harassment, personal attacks, and sharing anyone's private information (including student work) are not acceptable.

Report concerns privately to the maintainers through GitHub (the **Security → Report a vulnerability** form also reaches them privately). Reports will be handled confidentially.
